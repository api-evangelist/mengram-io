Mengram provides an AI memory platform that learns from your workflows, enabling agents like Claude, ChatGPT, and custom bots to retain context across sessions. It offers cloud‑hosted APIs, open‑source SDKs for Python and JavaScript, and a self‑hosted mode for local deployments. Features include searchable memory stores, integration connectors, and flexible pricing from a free tier to paid plans. The service emphasizes data privacy, with minimal data collection and compliance with GDPR, and supports developers through extensive documentation and open‑source tooling.

**Areas:** AI · Memory · Workflow · Automation · Platform

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
